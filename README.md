# Сложно сосредоточиться

Адаптивная веб-страница о том, почему бывает сложно сохранять концентрацию и
какие способы помогают сосредоточиться.

## Возможности

- адаптивная вёрстка для мобильных, планшетных и десктопных экранов;
- светлая и тёмная цветовые темы;
- автоматический выбор темы по системным настройкам;
- ручное переключение темы с сохранением выбранного режима;
- адаптивная галерея изображений;
- доступные состояния наведения и клавиатурного фокуса.

## Технологии

- HTML5;
- CSS3;
- Grid Layout;
- CSS-переменные;
- медиавыражения;
- JavaScript.

## Запуск проекта

Для просмотра откройте файл `index.html` в браузере.
